# 2026-10-29 — Daily Journal

## Work Completed

Investigated a late-training failure in the CarRacing DQN agent, where the policy stopped accelerating and evaluation performance collapsed. Tested enabling Double DQN and completed a fresh run using the original learning rate to check whether the agent could retain functional driving through the same training horizon.

## Runs and Artifacts

- **Original DQN:** `runs/dqn_carracing_baseline/2026-10-28_162515_seed42` — learning rate 0.00025, Double DQN disabled.
- **Double DQN:** `double_dqn` — learning rate 0.0001, Double DQN enabled, evaluated through episode 2050.
- **Double DQN:** `runs/double_dqn_no_low_lr/2026-10-29_123227_seed42` — learning rate 0.00025, Double DQN enabled, completed 2300 episodes.

The final run started from scratch and completed 576,975 environment steps in 7,954 seconds.

## Key Findings

- The original DQN's greedy evaluation mean dropped from 671.51 ± 97.28 at episode 2200 to -93.49 ± 0.52 at episode 2300.
- Action inspection showed that the original policy no longer used gas at episode 2300. Setting epsilon to 0.05 did not restore its earlier performance.
- With Double DQN enabled at the original learning rate, the agent achieved a mean evaluation reward of 431.53 ± 70.40 at episode 2300, compared with -93.45 ± 0.59 for the original DQN.
- The modified agent continued using gas and steering across all five inspected evaluation episodes.

## Decision

The immediate failure has been addressed. The Double DQN-enabled configuration with learning rate 0.00025 will serve as the baseline for subsequent CarRacing experiments. The possible role of value-estimation instability remains an unverified explanation and does not need to be resolved before moving forward.

**End-of-day takeaway:** The original DQN's policy stopped accelerating by episode 2300. Enabling Double DQN was enough to avoid the same failure under the same learning rate and training horizon, with the modified agent retaining functional driving and substantially better evaluation performance. This provides a practical basis for moving forward with the modified CarRacing baseline. The baseline-recovery experiment is complete; the next experiments can focus on improving the model's driving performance.
