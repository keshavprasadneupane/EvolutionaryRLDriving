# 2026-10-31 — Daily Journal

**Experiment 003.a — Leaky ReLU Double DQN:** Evaluated Leaky ReLU as an alternative to the original ReLU activation. Trained `dd_leaky_relu` for 2,300 episodes using seed 42. The selected episode 2300 checkpoint achieved **809.08 ± 89.98** across 50 evaluation seeds. Compared with the earlier ReLU-based Double DQN results, this supported Leaky ReLU as a better activation for the current CarRacing setup.

**Experiment 003.b — Resuming Training Without Replay Buffer Restoration:** Extended `dd_leaky_relu` from 2,300 to 3,500 episodes, resuming from the saved model checkpoint without restoring the previous replay buffer. The agent rebuilt its replay buffer through fresh environment interactions.

**Evaluation:** Swept 24 checkpoints using 10 evaluation seeds. Episode 2700 achieved the highest checkpoint score, with a mean reward of **840.2 ± 45.7**. Expanded evaluation across 50 seeds produced **858.48 ± 87.86**, with rewards ranging from 368.86 to 922.60.

**Outcome:** Successfully resumed training without replay-buffer restoration and obtained a checkpoint that outperformed the original episode 2300 checkpoint on the same 50 evaluation seeds. Although training showed considerable checkpoint fluctuations, this demonstrated that model-only resumption can work in this setup.

**Experiment 003.c — Leaky ReLU vs. PReLU:** Introduced channel-wise PReLU in the convolutional layers and feature-wise PReLU in the hidden fully connected layer, using the default initial slope of 0.25. Trained `dd_prelu` for 1,000 episodes.

**Evaluation:** Compared the episode 1000 PReLU and Leaky ReLU checkpoints across the same 50 fixed evaluation seeds. PReLU achieved **575.70 ± 107.92**, while Leaky ReLU achieved **618.67 ± 159.81**.

**Outcome:** Leaky ReLU achieved a 42.97-point higher mean reward, while PReLU showed lower variation across evaluation seeds. Both agents completed all 50 evaluation episodes without early termination. Retained Leaky ReLU as the preferred activation for the current Double DQN setup and concluded the PReLU experiment without extending training.
